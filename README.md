# BRO AI (W.E.D.N.E.S.D.A.Y. Pro)

> **Production-Grade Personal AI Assistant & Advanced Admin Control Center**

BRO AI is an intelligent, multi-persona conversational platform built with modern web technologies, multi-LLM orchestration, real-time telemetry, and a protected administrative control dashboard.

---

## 🌟 Key Features

### 🤖 Multi-LLM Intelligence & Persona Engine
- **Flexible Models**: Multi-LLM Ensemble, GPT-4o, Claude 3.5 Sonnet, Llama 3, Gemini 1.5 Pro.
- **Custom Personas**: Jarvis, Wednesday, Cyberpunk, Master Educator, Code Architect.
- **Real-Time Memory Isolation**: User-specific memory bank and isolated session management.

### 🛡️ Protected Admin Control Center (Admin-Only)
- Dedicated administrative panel for server-authorized admin (`karthikhruth@gmail.com`).
- **Live User Monitoring**: Real-time tracked active/online members with heartbeat detection.
- **User Governance**: One-click account ban, unban, and removal safeguards.
- **Audit & Security**: Real-time security event tracking and access log auditing.
- **Data Export**: Export user chats and platform telemetry into JSON, CSV, TXT, or PDF/HTML formats.

### 🔒 Privacy & Access Enforcement
- **OTP Verification**: Secure Mobile/Gmail registration and authentication system.
- **Access Limits**: 10-Minute unregistered guest access and trial management.

---

## 🚀 Tech Stack

- **Frontend**: React (Vite), Vanilla CSS design tokens, Lucide Icons
- **Backend**: Node.js, Express, Serverless API handlers
- **Deployment**: Vercel & GitHub Pages

---

## 🛠️ Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/karthikhruth11-hash/BRO-PRO.git
   cd BRO-PRO
   ```

2. **Install dependencies**:
   ```bash
   npm install
   cd client && npm install && cd ..
   ```

3. **Run locally**:
   ```bash
   npm run dev
   ```
